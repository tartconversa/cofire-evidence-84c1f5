# 资料口径

全部主体和观测均为本地合成资料，不代表企业、个人或真实设备。编号只在资料包内有意义，金额为人民币元，时刻统一为带 +08:00 的北京时间。空单元表示未知或不适用，不等于零；真假值用 true/false；数值不含千位分隔。CSV 行顺序不表示业务先后。时间区间采用左闭右开，除非字段说明另有规定。

班次是独立安排单位；readings 的行是班次内测点。treatment 为计划生物质热量占比，actual_ratio 是实际执行占比。carry_window_shifts 指前序影响可能持续的班次数，仅界定检查范围，不固定分析算法。available_at 是资料最早可知时点，数据包无预定有效性结论。风险结果中越限和蒸汽不足均为不利事件。下一轮建议可按工况接受或拒绝；状态 draft、approved、running、finished、paused 分别表示草案、已批准未开始、正在执行、已结束、暂停。effect_target 的负值表示希望降低单位蒸汽煤耗，阈值是用户配置，不是实测结果。
load 是额定蒸汽负荷比例，实际负荷使用 actual_load；计划与实际可不同。coal_per_steam 为每吨实际交付蒸汽的煤千克数，steam_tph 是测点对应小时产出。reviews 的 look_days 为开始日后日数，不是观测行号；风险以班次有无不利事件评估，不能按测点数稀释。偏离安排的 shift_id 保持不变。工况连续变量上的推广必须说明支持，资料未指定统计算法。

## boilers
合成炉组及前序影响范围。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| boiler_id | string | 炉组 |
| capacity_tph | number | 额定蒸汽吨每小时 |
| carry_window_shifts | integer | 前序影响检查范围 |

记录键：boiler_id。

## plans
已登记的炉组交叉安排。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| shift_id | string | 班次 |
| boiler_id | string | 炉组 |
| start | datetime | 开始时刻 |
| treatment | number | 计划热量替代比 |
| planned_load | number | 计划负荷 |
| coal_grade | string | 煤种 |
| registered_at | datetime | 登记时刻 |
| available_at | datetime | 可知时刻 |

记录键：shift_id。

## readings
测点保留实际执行与安全结局。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| reading_id | string | 测点 |
| shift_id | string | 班次 |
| within_shift | integer | 班次内顺序 |
| actual_ratio | number | 执行替代比 |
| moisture_pct | number | 含水率百分数 |
| coal_per_steam | number | 单位蒸汽煤耗千克每吨 |
| steam_tph | number | 蒸汽吨每小时 |
| emission_mg | number | 排放毫克每立方米 |
| emission_breach | boolean | 越限 |
| steam_shortfall | boolean | 供汽不足 |
| available_at | datetime | 可知时刻 |
| actual_load | number | 实际负荷 |

记录键：reading_id。

## deviations
安全停试记录及产生原因，不删除原安排。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| event_id | string | 记录 |
| shift_id | string | 班次 |
| kind | string | 偏离类型 |
| reason | string | 原因 |
| occurred_at | datetime | 发生时刻 |
| available_at | datetime | 可知时刻 |

记录键：event_id。

## reviews
分析者事先登记的声明范围与查看计划。主要指标 coal_per_steam，风险为两类不利事件。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| review_id | string | 登记 |
| registered_at | datetime | 登记时间 |
| look_days | string | 计划查看日以分号分隔 |
| effect_target | number | 期望煤耗差上界 |
| emission_risk_limit | number | 越限率上界 |
| steam_risk_limit | number | 不足率上界 |
| load_min | number | 负荷下界 |
| load_max | number | 负荷上界 |

记录键：review_id。

## next_trials
用以继续交接的业务请求，不包含批准结论。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| request_id | string | 请求 |
| boiler_id | string | 炉组 |
| ratio | number | 拟掺比 |
| load | number | 拟负荷 |
| coal_grade | string | 煤种 |
| moisture_pct | number | 拟含水率 |
| status | string | 执行状态 |
| start | datetime | 预定开始 |

记录键：request_id。
